# WasurePLY-to-3DTiles

Independent brick, based on `py3dtiles`, to convert `.ply` files from Wasure to 3D Tiles.

## Conda environment setup

A ready-to-use conda environment file is provided at:

- `environment.yml`

Create and activate the environment with:

```bash
conda env create -f environment.yml
conda activate wasureply-to-3dtiles
```

The environment installs `py3dtiles` through `pip`.
